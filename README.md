# 🎓 4º Período - Engenharia de Software - PUC Minas

Este repositório reúne os conteúdos desenvolvidos durante o 4º período do curso de Engenharia de Software na PUC Minas.
Cada pasta representa uma disciplina, contendo projetos, exercícios, anotações e materiais didáticos desenvolvidos por mim com base nas aulas, nos temas abordados e nos slides disponibilizados pelos professores, que também estão incluídos neste repositório como apoio.

## 📘 Sobre as Disciplinas

### 🚀 **Projeto de Software** – Casos de Uso e Modelagem
Modelagem de sistemas através de casos de uso, especificações funcionais e diagramas UML.
Material didático próprio, com base nas aulas sobre metodologias de desenvolvimento.

**Professor:** João Pedro Oliveira Batisteli

### 💻 **Interação Humano-Computador** – Design e Usabilidade
Princípios de UX/UI, prototipação, avaliação de interfaces e design centrado no usuário.
Conteúdo desenvolvido com foco em experiência do usuário e acessibilidade.

**Professora:** Lucila Ishitani

### 🌐 **Redes de Computadores** – Comunicação e Protocolos
Estudo de arquiteturas de redes, protocolos de comunicação, camadas OSI/TCP-IP e segurança de redes.
Material didático próprio, com base nas aulas sobre fundamentos de redes e comunicação de dados.

**Professor:** Alexandre Teixeira

### 📊 **Teoria dos Grafos** – Estruturas e Algoritmos
Implementações de grafos, algoritmos de busca, caminhos mínimos, árvores geradoras e conectividade.
Material didático próprio, com base nas aulas e conceitos fundamentais da teoria dos grafos.

**Professores:** Gabriel Barbosa da Fonseca / Zenilton Patrocínio

## 🧪 Tecnologias Utilizadas

- **Java** – Para implementações de algoritmos e estruturas
- **SQL** – Para consultas e manipulação de bases de dados
- **UML** – Para modelagem de sistemas e casos de uso
- **Markdown** – Para anotações e resumos
- **Git + GitHub** – Para controle de versão e compartilhamento

## ▶️ Como utilizar

1. Clone o repositório:
```bash
git clone https://github.com/marcosffp/4-periodo.git
```

2. Acesse a pasta da disciplina desejada:
```bash
cd 4-periodo/ProjetoDeSoftware
```

3. Compile e execute os códigos:
```bash
javac Exemplo.java
java Exemplo
```

Ou abra o projeto diretamente na sua IDE preferida.
